{% comment %} The container PagefindUI mounts into. What it holds until then is a plain input and its label, and nothing else: the engine and the UI are ~176 KB together, and a reference page is read far more often than it is searched, so nothing is fetched until somebody touches the field. That input is what they touch. PagefindUI renders its own, so this one is replaced the first time the field takes focus — see the loader in default.html. Focus, and only focus: there is no keystroke listener, because reaching the field is already the intent, and a keystroke cannot arrive without it. role="search" because the field sits inside
. Without it a screen-reader user has no search landmark on the page at all and has to walk into the navigation to find the field. {% endcomment %}
