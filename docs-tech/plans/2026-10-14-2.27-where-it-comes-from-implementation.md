# 2.27 — Where it comes from: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** /blocked names the country each refused source address is registered to, from ipverse's whole dataset held by the web process, and a row can stage that country for blocking — off until `country_lookup = true`.

**Architecture:** A new outbound request, off by default: the web process downloads ipverse's release archive (one `.tar.gz`, every `aggregated.json`) through a client that follows exactly GitHub's two redirects, keeps it in `<data_dir>/web/countries.tar.gz`, and builds a compact in-memory table — sorted, disjoint ranges per family in three parallel slices — that a binary search answers. The feed runner's tick loads and refreshes it daily, conditionally. /blocked gains a *Country* column, a *Block XX* row action that stages `country-<cc>` exactly as 2.26's Countries card does, and one status line. The core learns nothing; the protocol stays at 25 commands.

**Tech Stack:** Go 1.27.2 (`go.mod` toolchain), standard library only (`archive/tar`, `compress/gzip`, `encoding/json`, `net/netip`, `runtime/debug`), `golang.org/x/text` (2.26's `countryName`), chi, Go templates, Tailwind v4 (no new class), Playwright (`scripts/ui-check.mjs`).

**Spec:** `docs-tech/specs/2026-10-14-2.27-where-it-comes-from.md` (commit `fff1893f`). Read it before this plan; the amendments below override it where they disagree.

**Base:** `origin/main` once 2.26 has merged — today `feat/2.26-countries@5bd5f0a1` (*release: 2.26.0 — countries*), which is already rebased onto 2.25.2 (`11f6231d`, *Merge pull request #222 from jp1337/release/2.25.2*). Rebase this branch (`fff1893f`, the spec alone) onto it before Task 1. **Every diff below was generated on `5bd5f0a1` and applies there verbatim**, in task order. If `main` has moved by then and `git apply` refuses a hunk, re-apply it by hand on the file as it stands; the hunks that sit on 2.25.2's own lines are listed under *Hunks on 2.25.2's lines*.

## Global Constraints

- Version **2.27.0**, after 2.26.0. The core is untouched; the socket protocol stays at **25** commands.
- `country_lookup` (top-level, `web.toml`), default **false**; `EASYWALL_WEB_COUNTRY_LOOKUP`. Off: no lookup object, no request, no column; /blocked says in one line which key switches it on.
- Source: `https://github.com/ipverse/country-ip-blocks/releases/latest/download/country-ip-blocks.tar.gz`, CC0. Only `country/<cc>/aggregated.json` is read, `<cc>` in `shared.CountryCodes`.
- Redirects: `github.com` and `release-assets.githubusercontent.com` only, `https`, default port, at most **3**. The feeds' client keeps refusing every redirect.
- Refresh: at once with no copy, then every **24 h** after the last attempt, conditional; a failure keeps the table in memory and the copy on disk.
- Kept in `<data_dir>/web/countries.tar.gz`, mode `0600`.
- The column says **registered to**, never "from" or "located in" (D8).
- *Block XX* stages `country-<cc>` exactly as the Countries card's **Add**: at most **30** (`shared.MaxCountries`), never applies, never on a forwarded packet.
- `en` and `de` stay at exact parity; `fr` may have gaps.
- Verify UI by rendering it: `npm run check:ui`, then Chrome, both themes, 1600 / 900 / 390, `de` and `en`. Re-take the `blocked` screenshots in the same change.
- A generated file is rebuilt and grepped, never assumed: `web/static/style.css` (expected unchanged: no new class), `docs/_docs/changelog.md`.
- Every new test is seen red by breaking the code it covers; each task names the mutation.
- `git add` before running the guard tests (they read `git ls-files`); run `~/.local/bin/codespell --config .codespellrc` and `~/go/bin/golangci-lint run ./...` (never the `golangci-lint` on PATH).
- Fixtures use documentation addresses (RFC 5737, RFC 3849) — `feed_parse_test.go`'s rule.
- `docs/` is published, `docs-tech/` is not. No diagram is added.
- Never `git stash`. Restore a mutation with `git checkout -- <path>`.

## Review Focus

Inputs a person will meet that the spec does not name; each has its test in the owning task.

1. **An IPv4 source logged as `::ffff:a.b.c.d`** — named by its IPv4 country. → Task 2, `TestACountryIsLookedUpForBothFamilies` (`::ffff:192.0.2.80`).
2. **A host with no route out** — the column reads `—`, the line says *not loaded yet* and the last failure, and the next try waits an hour, then two, … — never a download every minute. → Task 3, `TestTheCountryLookupIsDue`; Task 4, `TestBlocked_SaysWhatTheCountryTableHolds`.
3. **A state directory that cannot be written** (full disk, read-only mount) — the downloaded table is used, and it is not due again until tomorrow. → Task 3, `TestAFetchThatCannotBeKeptIsNotFetchedAgainAtOnce`.
4. **GitHub moves the asset to a third host, or half a file arrives** — refused, the table in use stays, the line names the reason (*the server redirected, which is refused*; *the download broke off*). → Task 3, `TestTheCountryArchiveRefusesEveryOtherRedirect`, `TestABrokenArchiveKeepsTheTableInUse`.
5. **A thirty-first country, or a forged code, from a row** — nothing staged, the card's amber sentence or *could not be read*. → Task 4, `TestStageACountryFromALogRowRefuses`. (Blocking the operator's own country is judged at /apply, as for the card: 2.26's `TestTheVerdictNamesTheListBeforeTheCountry` and `TestApplyWaitsForACountrysFirstCopy`.)

```go
// The country lookup makes a request that leaves the host, so it is off unless
// switched on (spec D3). LoadConfig decodes into a zero Config, not into the
// shipped defaults (the 2.25.0 trap), so an absent key reads false — right
// only while false is also what config/web.toml ships, which is the first half.
func TestCountryLookupIsOffUnlessSwitchedOn(t *testing.T) {
	if shared.WebDefault().CountryLookup {
		t.Fatal("config/web.toml ships country_lookup = true; the lookup must be asked for")
	}
	load := func(body string) bool {
		t.Helper()
		cfg, err := LoadConfig(writeTempConfig(t, body))
		if err != nil {
			t.Fatalf("LoadConfig: %v", err)
		}
		return cfg.CountryLookup
	}
	if load(`bind_addr = "127.0.0.1:1"`) {
		t.Error("a web.toml without country_lookup reads it as on")
	}
	if !load("country_lookup = true\n") {
		t.Error("country_lookup = true reads as off")
	}
	t.Setenv("EASYWALL_WEB_COUNTRY_LOOKUP", "true")
	if !load(`bind_addr = "127.0.0.1:1"`) {
		t.Error("EASYWALL_WEB_COUNTRY_LOOKUP=true did not switch it on")
	}
}
```

```go
package web

import (
	"archive/tar"
	"cmp"
	"compress/gzip"
	"encoding/binary"
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"net/netip"

	"strings"

	"github.com/jp1337/easywall/internal/shared"
)

// The country column on /blocked (2.27, spec D4): which country each address
// block is registered to, from ipverse's whole dataset, held by this process
// in memory. A lookup is a label on a row, never a rule — the core never sees
// this table.

// countryArchiveMaxUnpacked bounds what one archive may decompress to: 8 657 778
// bytes on 2026-10-14, so 64 MiB is 7.7 times that. A body is capped at
// feedMaxBody before it gets here, and deflate expands at most about 1 032:1,
// so without this an 8 MiB bomb could make the reader inflate gigabytes.
// A var so a test can prove the bound without a 64 MiB fixture.
var countryArchiveMaxUnpacked int64 = 64 << 20

var (
	errCountryArchiveEmpty   = errors.New("country archive: not one country's aggregated.json")
	errCountryArchiveTooLong = errors.New("country archive: larger than it may unpack to")
)

// countryRanges is one family's table: sorted, disjoint ranges, each with the
// index of its code in shared.CountryCodes. IPv4 is the address as a number;
// IPv6 is its first 64 bits, because no delegation is longer than a /64 (the
// longest across all 69 614 on 2026-10-14 is /64).
//
// Three parallel slices, not a slice of structs with a netip.Prefix: measured
// on the whole dataset, 17 bytes a range against 64 (the plan's D4 numbers).
type countryRanges struct {
	start, end []uint64
	cc         []uint8
}

type countryTable struct {
	v4, v6    countryRanges
	countries int
}

// lookup is the country addr's block is registered to, lower case, or "" when
// none is — a private or reserved address, one between two ranges, or no table.
func (t *countryTable) lookup(addr netip.Addr) string {
	addr = addr.Unmap()
	if t == nil || !addr.IsGlobalUnicast() || addr.IsPrivate() {
		return ""
	}
	rs, k := &t.v6, addrKey(addr)
	if addr.Is4() {
		rs = &t.v4
	}
	i, found := slices.BinarySearch(rs.start, k)
	if !found {
		i--
	}
	if i < 0 || k > rs.end[i] {
		return ""
	}
	return shared.CountryCodes[rs.cc[i]]
}

// ranges is how many ranges the table holds, both families.
func (t *countryTable) ranges() int {
	if t == nil {
		return 0
	}
	return len(t.v4.start) + len(t.v6.start)
}

// addrKey is an IPv4 address as a number, or an IPv6 address's first 64 bits.
func addrKey(a netip.Addr) uint64 {
	if a.Is4() {
		b := a.As4()
		return uint64(binary.BigEndian.Uint32(b[:]))
	}
	b := a.As16()
	return binary.BigEndian.Uint64(b[:8])
}

// prefixRange is p as the first and last key it covers. An IPv6 prefix longer
// than /64 covers its whole /64.
// shortcut: a /65../128 labels its whole /64; none exists in the data (2026-10-14).
func prefixRange(p netip.Prefix) (uint64, uint64) {
	width := 64
	if p.Addr().Is4() {
		width = 32
	}
	host := width - min(p.Bits(), width)
	start := addrKey(p.Addr())
	if host == 64 {
		return start, ^uint64(0)
	}
	return start, start | (uint64(1)<<host - 1)
}

// countryPrefix is one prefix of the archive, already a range: 24 bytes
// where a netip.Prefix and its code took 40.
type countryPrefix struct {
	start, end uint64
	bits, cc   uint8
}

func newCountryPrefix(p netip.Prefix, cc uint8) countryPrefix {
	s, e := prefixRange(p)
	return countryPrefix{start: s, end: e, bits: uint8(p.Bits()), cc: cc} // #nosec G115 -- 0..128
}

// buildCountryRanges sorts and merges one family. Two prefixes are either
// disjoint or one inside the other; inside, the narrower one wins — ipverse
// lists 123.100.242.0/24 under DE inside SG's 123.100.240.0/22 (2026-10-14).
// Neighbours of one country merge into one range.
func buildCountryRanges(ps []countryPrefix) countryRanges {
	slices.SortFunc(ps, func(a, b countryPrefix) int {
		if a.start != b.start {
			return cmp.Compare(a.start, b.start)
		}
		return int(a.bits) - int(b.bits)
	})
	// A nested prefix adds at most two ranges; most merge. Sized for the
	// common case, so the table's slices are not twice what they hold.
	rs := countryRanges{
		start: make([]uint64, 0, len(ps)), end: make([]uint64, 0, len(ps)), cc: make([]uint8, 0, len(ps)),
	}
	add := func(s, e uint64, cc uint8) {
		if n := len(rs.start); n > 0 && rs.cc[n-1] == cc && rs.end[n-1] != ^uint64(0) && rs.end[n-1]+1 == s {
			rs.end[n-1] = e
			return
		}
		rs.start, rs.end, rs.cc = append(rs.start, s), append(rs.end, e), append(rs.cc, cc)
	}
	for _, p := range ps {
		s, e := p.start, p.end
		n := len(rs.start)
		if n == 0 || rs.end[n-1] < s {
			add(s, e, p.cc)
			continue
		}
		// p lies inside the last range: sorted by start, every earlier range
		// ends before the last one begins.
		if rs.cc[n-1] == p.cc {
			continue
		}
		outerEnd, outerCC := rs.end[n-1], rs.cc[n-1]
		if rs.start[n-1] == s {
			rs.start, rs.end, rs.cc = rs.start[:n-1], rs.end[:n-1], rs.cc[:n-1]
		} else {
			rs.end[n-1] = s - 1
		}
		add(s, e, p.cc)
		if e < outerEnd {
			add(e+1, outerEnd, outerCC)
		}
	}
	rs.start, rs.end, rs.cc = slices.Clip(rs.start), slices.Clip(rs.end), slices.Clip(rs.cc)
	return rs
}

// parseCountryArchive reads ipverse's release archive: every
// country/<cc>/aggregated.json, nothing else. A code not in
// shared.CountryCodes is skipped; a prefix that does not parse is skipped, as
// parseFeed counts one. Any error — a truncated archive, a file that is not
// JSON, more than it may unpack to, not one country — returns no table, and
// the caller keeps the one it has.
func parseCountryArchive(r io.Reader) (*countryTable, error) {
	gz, err := gzip.NewReader(r)
	if err != nil {
		return nil, fmt.Errorf("country archive: %w", err)
	}
	lr := &io.LimitedReader{R: gz, N: countryArchiveMaxUnpacked}
	tr := tar.NewReader(lr)
	var v4, v6 []countryPrefix
	seen := map[uint8]bool{}
	for {
		hdr, err := tr.Next()
		if errors.Is(err, io.EOF) {
			break
		}
		if err != nil {
			return nil, fmt.Errorf("country archive: %w", err)
		}
		if ok, _ := path.Match("country/*/aggregated.json", hdr.Name); !ok || hdr.Typeflag != tar.TypeReg {
			continue
		}
		idx := slices.Index(shared.CountryCodes, strings.Split(hdr.Name, "/")[1])
		if idx < 0 {
			continue
		}
		if hdr.Size > feedMaxBody {
			return nil, errCountryArchiveTooLong
		}
		var doc struct {
			Prefixes struct {
				IPv4 []string `json:"ipv4"`
				IPv6 []string `json:"ipv6"`
			} `json:"prefixes"`
		}
		if err := json.NewDecoder(tr).Decode(&doc); err != nil {
			return nil, fmt.Errorf("country archive: %s: %w", hdr.Name, err)
		}
		cc := uint8(idx) // #nosec G115 -- TestCountryCodesFitAByte
		for _, list := range [][]string{doc.Prefixes.IPv4, doc.Prefixes.IPv6} {
			for _, s := range list {
				p, ok := parseEntry(s)
				if !ok {
					continue
				}
				seen[cc] = true
				if p.Addr().Is4() {
					v4 = append(v4, newCountryPrefix(p, cc))
				} else {
					v6 = append(v6, newCountryPrefix(p, cc))
				}
			}
		}
	}
	if lr.N <= 0 {
		return nil, errCountryArchiveTooLong
	}
	if len(seen) == 0 {
		return nil, errCountryArchiveEmpty
	}
	return &countryTable{v4: buildCountryRanges(v4), v6: buildCountryRanges(v6), countries: len(seen)}, nil
}
```

```go
import (
```

```go
// The country lookup (2.27, spec §1): ipverse's release archive, fetched once
// a day by this process when web.toml says country_lookup = true, kept in
// <data_dir>/web/countries.tar.gz, and asked by /blocked for each row's
// source. Off, none of this exists: NewServer builds no lookup, so nothing
// here can make a request.

// countryArchiveURL is ipverse's newest release asset: every country's
// aggregated.json in one file, 1 747 173 bytes on 2026-10-14. It answers
// through two redirects, and the last host honours If-None-Match and
// If-Modified-Since with a 304 (measured with curl -L).
const countryArchiveURL = "https://github.com/ipverse/country-ip-blocks/releases/latest/download/country-ip-blocks.tar.gz"

// countryLookupKey is the lookup's entry in feed_fetch.json — validators, last
// attempt, failures — beside the feeds'. Not "country-": it is no feed, and
// nothing that walks the feeds' ids reaches it.
const countryLookupKey = "country_lookup"

// countryArchiveHosts and countryArchiveMaxRedirects are the only redirects
// the download follows (spec D2). Measured 2026-10-14: github.com/…/latest/
// download/… → 302 github.com/…/download/latest/… → 302
// release-assets.githubusercontent.com/…. The feeds' client refuses every
// redirect (2.23); this one is its own client, not a loosening of theirs.
var countryArchiveHosts = []string{"github.com", "release-assets.githubusercontent.com"}

const countryArchiveMaxRedirects = 3

// countryArchiveRedirect follows a redirect only over https, on the default
// port, to one of countryArchiveHosts, and at most countryArchiveMaxRedirects
// of them. via holds the requests already sent, so len(via) is the number of
// the redirect being asked about.
func countryArchiveRedirect(req *http.Request, via []*http.Request) error {
	if len(via) > countryArchiveMaxRedirects || req.URL.Scheme != "https" || req.URL.Port() != "" ||
		!slices.Contains(countryArchiveHosts, req.URL.Hostname()) {
		return errFeedRedirect
	}
	return nil
}

type countryLookup struct {
	path  string
	store *feedStore
	http  *http.Client
	now   func() time.Time
	table atomic.Pointer[countryTable]
	busy  sync.Mutex
}

func newCountryLookup(path string, store *feedStore) *countryLookup {
	return &countryLookup{
		path: path, store: store, now: time.Now,
		// The zero Transport is http.DefaultTransport, as the feeds' is.
		http: &http.Client{Timeout: feedFetchTimeout, CheckRedirect: countryArchiveRedirect},
	}
}

// country is the code addr's block is registered to, lower case; "" when
// none is, or while no table is loaded.
func (l *countryLookup) country(addr netip.Addr) string { return l.table.Load().lookup(addr) }

// countryLookupStatus is the one line /blocked shows about the table.
type countryLookupStatus struct {
	Loaded     bool
	Countries  int
	Ranges     int
	CheckedAt  time.Time // the last attempt; zero before the first
	LastError  string    // one of AllFeedErrors; "" after a success
	HTTPStatus int
}

func (l *countryLookup) status() countryLookupStatus {
	st := l.store.fetchState(countryLookupKey)
	out := countryLookupStatus{CheckedAt: st.LastAttempt, LastError: st.LastError, HTTPStatus: st.HTTPStatus}
	if t := l.table.Load(); t != nil {
		out.Loaded, out.Countries, out.Ranges = true, t.countries, t.ranges()
	}
	return out
}

// load reads the copy a previous run kept. Missing or unreadable, the table
// stays empty and due says fetch.
func (l *countryLookup) load() {
	raw, err := os.ReadFile(l.path) // #nosec G304 -- a fixed name in this process's own state dir
	if err != nil {
		if !errors.Is(err, os.ErrNotExist) {
			slog.Warn("country table not read; fetching it again", "path", l.path, "error", err)
		}
		return
	}
	t, err := parseCountryArchive(bytes.NewReader(raw))
	if err != nil {
		slog.Warn("country table on disk unreadable; fetching it again", "path", l.path, "error", err)
		return
	}
	l.table.Store(t)
	// A build allocates about 69 MB for a table that keeps 3.6 MB. Left to
	// the scavenger, easywall-web stayed 27 MB above its size without the
	// lookup; handed back at once, 10 MB after a download and 4 MB after a
	// restart (measured, 2.27 plan, D4).
	debug.FreeOSMemory()
}

// due: with no table, at once — unless a failure's backoff is running; with
// one, a day after the last attempt, as a country's feed (spec D1).
func (l *countryLookup) due(now time.Time) bool {
	st := l.store.fetchState(countryLookupKey)
	if st.LastAttempt.IsZero() || l.table.Load() == nil && st.Failures == 0 {
		return true
	}
	return !now.Before(nextFeedAttempt(st, shared.CountryInterval))
}

// refresh fetches the archive — conditionally while a table is loaded — and
// swaps the new table in whole. Any failure keeps the table in use and the
// copy on disk.
func (l *countryLookup) refresh() {
	if !l.busy.TryLock() {
		return
	}
	defer l.busy.Unlock()
	st := l.store.fetchState(countryLookupKey)
	have := l.table.Load() != nil
	st.LastAttempt = l.now()
	l.store.setFetchState(countryLookupKey, st)

	req, err := http.NewRequest(http.MethodGet, countryArchiveURL, nil)
	if err != nil {
		l.fail(st, err)
		return
	}
	req.Header.Set("User-Agent", feedUserAgent())
	if have {
		setValidators(req, st)
	}
	res, err := readFeedResponse(l.http, req, have)
	if err != nil {
		l.fail(st, err)
		return
	}
	st.Status = FeedUnchanged
	if !res.notModified {

		st.ETag, st.LastModified, st.Status = res.etag, res.lastModified, FeedUpdated
	}

}
```
