> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** /blocked filters by country over the whole ring. The feed catalogue stops recommending blocklist.de "all" and recommends its SSH list instead. A list that really shrank is taken after a day.

**Architecture:** The core gains one protocol field (`before`, a seq bound) and an in-memory shrink watch in `UpdateFeed`. **Spec:** `docs-tech/specs/2026-10-15-2.29-which-lists-and-which-country.md` (research: `docs-tech/specs/2026-10-15-2.29-feeds-research.md`)

## Review Focus

1. A core one version older that ignores `before` must not make the web process loop forever (D9): the page sees the same entries again.
2. A ring that went backwards (core restarted without spill file) while a country is set: the tail must give the whole view, not 204 forever.
3. A country set while the lookup is off or the table not loaded: the page must work as if no country was given, with no select shown.
4. An hourly feed that shrinks once from a truncated download and then recovers: never accepted; the watch resets on the next normal fetch.
5. A shrink watch on a feed switched off and on again: a feed not in Current takes any size (existing rule), and the watch for it starts clean.

```go
// feedNow is the clock UpdateFeed reads; a var so the shrink watch's day can
// be tested without waiting one.
var feedNow = time.Now

// shrinkWatch is how long a live list has been refused as a shrink (2.29 D5,
// D6): the first refusal of the current run and how many followed. Memory
// only — a refusal leaves feeds.json byte-identical, and a restart only
// starts the day again.
type shrinkWatch struct {
	since time.Time
	seen  int
}

// shrinkAcceptAfter and shrinkAcceptSeen: a truncated download is one broken
// fetch; a list that stays small for a day and three fetches is a real shrink.
const (
	shrinkAcceptAfter = 24 * time.Hour
	shrinkAcceptSeen  = 3
)
```

```go
		if f.shrink == nil {
			f.shrink = map[string]shrinkWatch{}
		}
		w := f.shrink[p.ID]

		}
```

```go
// countryEntries reads the whole ring a page at a time and keeps the entries
// whose source the country table places in f.Country (2.29 D7): exact, not a
// sample of the newest 200. The second value is true when the core ignored
// before — an older core (D9) — and the paging stopped there.
func (s *Server) countryEntries(f shared.PacketLogFilter) (*shared.PacketLogResult, bool, error) {
	q := f
	q.Country, q.Limit, q.Before = "", shared.PacketLogMaxLimit, 0
	keep := f.EffectiveLimit()
	var out *shared.PacketLogResult
	for {
		res, err := s.client.GetPacketLog(q)
		if err != nil {
			return nil, false, err
		}
		if out == nil {
			first := *res
			first.Entries, first.Matched = []shared.PacketLogEntry{}, 0
			out = &first
		}
		for _, e := range res.Entries {
			if q.Before != 0 && e.Seq >= q.Before {
				return out, true, nil
			}
			if s.lookup.country(e.Src) != f.Country {
				continue
			}
			out.Matched++
			if len(out.Entries) < keep {
				out.Entries = append(out.Entries, e)
			}
		}
		if len(res.Entries) < q.Limit {
			return out, false, nil
		}
		q.Before = res.Entries[len(res.Entries)-1].Seq
	}
}
```
