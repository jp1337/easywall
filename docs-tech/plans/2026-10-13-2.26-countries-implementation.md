# 2.26 — Countries: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An operator blocks the address space of individual countries — each switched on by itself, all off by default, checked after the allowlist and after every feed — through a *Countries* card on /blocklist.

**Architecture:** A country is a feed with the id `country-<cc>` in `Rules.Feeds` (spec D3, D4). `shared` gains the 238 codes, the id helpers, the 30-country cap and a per-id breadth limit; the core builds country rules after the lists' and validates them with the country limit; the web process fetches ipverse's `aggregated.json` (one URL, so the existing `If-None-Match` path applies), names countries with `golang.org/x/text/language/display`, and adds the card, the /blocked chip and the /apply labels. Fetching, storing, counting, the shrink guard, the lockout check and the packet log are the 2.23 machinery, unchanged. The protocol stays at 25 commands.

**Tech Stack:** Go 1.27.2 (`go.mod` toolchain), `golang.org/x/text` v0.43.0 (already a direct requirement — `display`, `unicode/norm`; `collate` in one test only), google/nftables v0.3.0, chi, Go templates, Tailwind v4, Playwright (`scripts/ui-check.mjs`).

**Spec:** `docs-tech/specs/2026-10-13-2.26-countries.md` (commit `785bb140`). Read it before this plan; the amendments below override it where they disagree.

**Base:** `origin/main` at the time the branch is cut. If 2.25.2 (`docs-tech/specs/2026-10-13-2.25.2-the-tail-sends-what-is-new.md`) has merged by then, it touched `internal/web/handler_blocked.go` (`feedNames`) and `web/templates/blocked.html` (the row markup). Task 4's two hunks there are small; re-apply them by hand on 2.25.2's version if `git apply` refuses, and the release task's compare link starts at `v2.25.2`.

## Global Constraints

- Version **2.26.0**. Block only, on every port (D1). No allow-mode, no per-port scope, no continents.
- Ids are `country-<cc>`, `<cc>` lower-case ISO 3166-1 alpha-2 from `shared.CountryCodes` (238, never shortened).
- At most **30** countries (`shared.MaxCountries`), enforced by `ValidateRules` (core) and by the card (web, before the core is asked).
- Source: `https://raw.githubusercontent.com/ipverse/country-ip-blocks/master/country/<cc>/aggregated.json`, CC0 1.0, every **24 h** at the install's offset (D9).
- Breadth: a country may hold /4 (IPv4) and /12 (IPv6); every other feed keeps /8 and /16.
- Countries are checked **after** every list and own feed (D8) and after the allowlist (unchanged).
- Names come from `golang.org/x/text/language/display` in the page's language; no locale key per country (D7). `go.mod` does not change.
- No x/text in `easywall-core`; the socket protocol stays at **25** commands.
- `en` and `de` stay at exact parity; `fr` may have gaps (it has none of the feed keys today).
- Verify UI by rendering it: `npm run check:ui`, then Chrome, both themes, 1600 / 900 / 390, `de` and `en`. Re-take `blocklist` and `blocked` screenshots in the same change.
- A generated file is rebuilt and grepped, never assumed: `web/static/style.css`, `docs/_docs/changelog.md`.
- Every new test is seen red by breaking the code it covers; each task names the mutation.
- `git add` before running the guard tests (they read `git ls-files`); run `~/.local/bin/codespell --config .codespellrc` and `~/go/bin/golangci-lint run ./...` (never the `golangci-lint` on PATH).
- `docs/` is published, `docs-tech/` is not. No diagram is added; if one is ever needed, draw.io.
- Never `git stash` (the stash is shared with other sessions). Restore a mutation with `git checkout -- <file>`.

```go
import (
	"slices"
	"strings"
	"time"
)

// Countries (2.26): one feed per country, id "country-<cc>", switched on in
// Rules.Feeds beside the catalogue (spec D3, D4). The source is
// ipverse/country-ip-blocks (CC0 1.0), built daily from the five RIRs'
// delegation files. Like the catalogue, the core knows only which ids exist.

// FeedFormatIPverse is ipverse's country/<cc>/aggregated.json:
// {"prefixes":{"ipv4":[…],"ipv6":[…]}}. One file for both families, so a
// country is a one-URL feed and its daily refresh is a conditional GET — a
// 304 when nothing changed (measured 2026-10-13). The two .txt files the spec
// named would make it a two-URL feed, which refreshFrom never asks
// conditionally, and six countries publish no ipv6 file at all.
const FeedFormatIPverse FeedFormat = "ipverse-json"

const countryFeedPrefix = "country-"

// MaxCountries is how many countries may be switched on (spec D5). Every
// refresh reads GET_FEEDS for every id and rewrites feeds.json whole, and
// every country adds two sets and two to four rules.
// TestIntegration_ARealisticRuleSetWithFeedsApplies loads the thirty largest
// at their measured sizes; this is not raised past what that test passes.
const MaxCountries = 30

// CountryInterval: ipverse rebuilds once a day, between 01:23 and 01:25 UTC
// on the five days measured (spec D9).
const CountryInterval = 24 * time.Hour

// FeedMaxBitsV4Country and FeedMaxBitsV6Country are a country's breadth
// limits. The lists' /8 and /16 refuse the United States: its aggregated
// IPv4 holds 16.0.0.0/6 and 32.0.0.0/6, and its IPv6 2630::/16 (2026-10-13).
// Two bits beyond the broadest v4, and an RIR's whole /12 for v6.
const (
	FeedMaxBitsV4Country = 4
	FeedMaxBitsV6Country = 12
)

// countryURLStem + cc + "/aggregated.json" is where a country's list is
// fetched. raw.githubusercontent.com answers it with an ETag and honours
// If-None-Match.
const countryURLStem = "https://raw.githubusercontent.com/ipverse/country-ip-blocks/master/country/"

// case: its 238 country directories on 2026-10-13. Never shortened (the
// catalogue's rule, invariants.md): a code removed here makes ValidateRules
// refuse every rule set that switched it on, at boot included.
// TestCountryCodesAreNeverRemoved holds that. A code ipverse later drops
// fails its fetch with a 404 and keeps its last copy.

	cc, ok := strings.CutPrefix(id, countryFeedPrefix)
	return cc, ok && slices.Contains(CountryCodes, cc)
}

// IsCountryFeedID reports whether id is a country's.
func IsCountryFeedID(id string) bool {
	_, ok := CountryCode(id)
	return ok
}

		ID: CountryFeedID(cc), Name: strings.ToUpper(cc),

		Interval: CountryInterval,
		Homepage: "https://github.com/ipverse/country-ip-blocks",
		Terms:    "https://github.com/ipverse/country-ip-blocks/blob/master/LICENSE",
	}

// FeedMaxBits is the broadest prefix a feed may carry, per family: a
// country's limits for a country id, the lists' for every other.
func FeedMaxBits(id string) (v4, v6 int) {
	if IsCountryFeedID(id) {
		return FeedMaxBitsV4Country, FeedMaxBitsV6Country
	}
	return FeedMaxBitsV4, FeedMaxBitsV6
}

// FeedRuleOrder is ids in the order the kernel's rules check them (spec D8):
// the lists in the order they were switched on, then the countries in theirs.
// An address on both is counted and logged by the list, which says more about
// why it is refused. The core builds the rules in this order and the lockout
// verdict names the first feed in it.
func FeedRuleOrder(ids []string) []string {
	out := make([]string, 0, len(ids))
	for _, id := range ids {
		if !IsCountryFeedID(id) {
			out = append(out, id)
		}
	}
	for _, id := range ids {
		if IsCountryFeedID(id) {
			out = append(out, id)
		}
	}
	return out
}
```

```go
// The Countries card on /blocklist (2.26, spec §2). A country is a feed with
// the id country-<cc>; the card stages the country subset of Rules.Feeds and
// leaves every other id where it is.

// countryName is what country cc is called in lang — "de" is "Deutschland"
// under de and "Germany" under en (spec D7): CLDR's names through x/text, so
// no locale key per country. The code in capitals when x/text has none.
func countryName(lang, cc string) string {
	if r, err := language.ParseRegion(cc); err == nil {
		if n := display.Regions(language.Make(lang)).Name(r); n != "" {
			return n
		}
	}
	return strings.ToUpper(cc)
}

// countriesNext is what a save of the Countries card stages: before with add
// appended, or with remove taken out. Every id that is not a country keeps
// its place. The second value is a flash key when nothing is staged.
func countriesNext(before []string, add, remove string) ([]string, string) {
	next := append([]string{}, before...)
	switch {
	case remove != "" && shared.IsCountryFeedID(remove):
		return slices.DeleteFunc(next, func(id string) bool { return id == remove }), ""
	case remove == "" && shared.IsCountryFeedID(add):
		if slices.Contains(next, add) {
			return next, ""
		}
		n := 0
		for _, id := range next {
			if shared.IsCountryFeedID(id) {
				n++
			}
		}
		if n >= shared.MaxCountries {
			return nil, "feeds_error_too_many_countries"
		}
		return append(next, add), ""
	}
	return nil, "save_error" // an id that is not a country: a forged form
}

// handleCountriesPOST adds or removes one country. A form that carries both
// fields only removes; the card never sends both, because each Remove is a
// form of its own.
func (s *Server) handleCountriesPOST(w http.ResponseWriter, r *http.Request) {
	back := "/blocklist#countries"
	state, err := s.client.GetRules()
	if err != nil {
		slog.Warn("get rules error", "error", err)
		s.setFlash(w, r, "save_error")
		http.Redirect(w, r, back, http.StatusSeeOther)
		return
	}
	add, remove := r.PostFormValue("add"), r.PostFormValue("remove")
	next, refused := countriesNext(state.Staged.Feeds, add, remove)
	if refused != "" {
		slog.Info("countries not staged", "reason", refused)
		s.setFlash(w, r, refused)
		http.Redirect(w, r, back, http.StatusSeeOther)
		return
	}
	if err := s.client.SaveRules("feeds", next); err != nil {
		slog.Warn("save countries error", "error", err)
		s.setFlash(w, r, "save_error")
		http.Redirect(w, r, back, http.StatusSeeOther)
		return
	}
	// After the save, as the Feeds card does: the runner's own GET_RULES
	// already sees it staged. Only for a country that was not staged before.
	if remove == "" && !slices.Contains(state.Staged.Feeds, add) {
		s.refreshFeedNow(add)
	}
	s.setFlash(w, r, "saved")
	http.Redirect(w, r, back, http.StatusSeeOther)
}
```

```markdown
# Block a country

A country is a list of the networks registered to it. Like a
[feed]({{ '/docs/features/feeds/' | relative_url }}), it is checked **after**
your allowlist, so an address you allow stays reachable. An address that is in a
feed as well is counted and logged by the feed.

## Add a country

1. Open **Blocklist** and scroll to **Countries**.
2. Choose the country and press **Add**. It is staged like any rule.
3. Open **Apply Rules** and press **Apply now**. If the verdict names the
   country, your own address is in it: add that address to the
   [allowlist]({{ '/docs/features/allowlist/' | relative_url }}) first.
4. Press **Confirm rules** within the window, or the country rolls back.

**Remove** takes it out again; apply and confirm as above. The row's
*Last refresh*, *Entries* and warnings read like a feed's: see
[When a feed fails]({{ '/docs/features/feeds/' | relative_url }}#when-a-feed-fails).

## What it cannot do

- **A registration is not a location.** The list says where a network was
  registered, not where a packet comes from. VPNs, cloud regions and Tor exits
  do not follow it.
- **It only blocks.** *Allow only these countries* is not this feature. Its
  inverse would block the address you manage the host from as soon as you
  travel.
- **Blocking the United States blocks Googlebot and Bingbot.** A crawler that
  cannot reach your site drops it from search. Allowlist the ranges the vendors
  publish
  ([Googlebot](https://developers.google.com/static/crawling/ipranges/common-crawlers.json),
  [Bingbot](https://www.bing.com/toolbox/bingbot.json)), or leave it off.

Where the lists come from, how often they change and the limits: the
[reference]({{ '/docs/features/feeds/' | relative_url }}#countries).
```
