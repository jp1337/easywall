# 2.21.1 — What it offers, it can do

A patch to 2.21.0, from walking `/blocked` in Chrome after the release. Every
finding below was caused by 2.21.0, so none is carried forward.

## Findings

| # | Finding | Measured |
|---|---|---|
| F9 | Row actions are offered where they could not have let the packet through | The input chain is *modules → blacklist → whitelist → ports → final drop* (`internal/core/nftables.go` Apply; `shared.Reachable` steps 5–9). A whitelist entry cannot rescue a packet a module or the blacklist dropped; a port rule can only rescue a default drop. "Open 3389" on a port-scan row invites the scanner |
| F12 | The live tail destroys keyboard focus | A focused row button is replaced every poll; `document.activeElement` became `BODY` after 12 s |
| F3 | The live tail moves rows under the pointer | A click aimed at a row lands on the row that slid into its place; element refs vanished between two tool calls |
| F13 | "Log blocked" / "Log blacklist" say *writes … to the system log* | False since 2.21.0 — they appear on `/blocked` |
| F2 | Row action text rests at 55 % opacity | ≈ 4.2 : 1, below the 4.5 : 1 WCAG AA asks of text. `.row-action` is DESIGN.md's rule for an icon |
| F1 | German says *Whitelist/Blacklist* on `/blocked` and the apply screen, *Erlaubnisliste/Sperrliste* everywhere else | `locales/de.json` |
| F7 | The demo's refused packets come from networks its own blacklist and whitelist already cover | Every blacklist click in the demo answered "already there" |
| F4 | The filter form puts empty fields in the URL | `?src=&dst=&port=3389&proto=&rule=portscan&in=` |
| F5 | An unreadable filter clears the fields | The operator cannot see what they typed wrong |
| F8 | The header counts rule changes only; the apply screen counts rules and configuration | "2 staged" against "3 changes" |

## Decisions

| Question | Decision | Why |
|---|---|---|
| Which actions a row offers | Whitelist on *default drop*, *bogon* (the bogon filter exempts whitelisted sources) and *another rule* (custom rules run after the whitelist). Blacklist on every rule but *blacklist*. Open the port on *default drop* only. A blacklist row offers a link to the blacklist page instead | Derived from the chain order; the page must not suggest an action with no effect on the packet it shows |
| Live tail | Skip the poll while the pointer or keyboard focus is inside the table, and say so in the toolbar | The fragment is the whole view, so the first poll after leaving catches up. Ceiling: a screen reader's browse cursor does not move focus, so it is not detected |
| Row action de-emphasis | Muted ink colour at full opacity, full ink on row hover/focus; DESIGN.md amended openly | Colour keeps ≥ 4.5 : 1; opacity cannot for text |
| Empty fields in the URL | A readable filter whose query is not canonical redirects once to the canonical URL | No JavaScript; the URL stays the state |
| Header count | The apply screen's own total (`buildPreview`) | One number, one source |

**Not in this patch:** the Options page rewrite asked for on 2026-09-23 — a
feature, specified separately. F13 corrects only the two sentences that are false.
