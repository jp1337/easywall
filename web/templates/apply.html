How applying works

{{/* Numbered because this genuinely is a sequence and the order is the information — not as decoration. */}}
  1. Rules go live
    The staged set is pushed to the kernel immediately and starts filtering traffic.
  2. You check
    Open a second connection — keep the current one — and confirm SSH and your services still answer.
  3. Confirm, or do nothing
    Confirming keeps the new rules. Doing nothing restores the previous set when the window closes, which is what saves you if you just locked yourself out.

The window length

How long you get before an unconfirmed apply is rolled back is set under system settings.

Short enough that a lockout resolves itself quickly; long enough to actually test. The default is 120 seconds.
