How a redirect reads

A rule sends traffic that arrives on the incoming port to the destination port on this same host — 8080 → 80 means a request to 8080 is served by whatever listens on 80.

The incoming port still needs to be open. Add it under port rules, or the redirect never gets reached.

Ports below 1024

Redirecting a privileged port to a high one is the usual way to run a service without root. Check that nothing else already holds the destination port.
